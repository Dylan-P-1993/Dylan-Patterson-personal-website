Behind the Code

I am a full-stack developer and indie game designer based in Indiana. My transition into software engineering is driven by a lifelong passion for worldbuilding and complex systems—whether that means architecting a React application, designing an interactive REST API, or managing state for a database.

What I Do

  • Web Development: Building full-stack applications utilizing HTML, CSS, JavaScript, and React.
  • Game Design: Developing 3D action-survival games in Unreal Engine, complete with custom character mechanics and logic blueprints.
  • Tabletop RPGs: Acting as a Game Master and player for Pathfinder 1e, Daggerheart, and Starfinder. I design extensive homebrew rules, custom classes, and deep lore for my fantasy setting, Viridia.

Off the Keyboard

When I am not in Visual Studio Code or Unreal Engine, you can usually find me deep into heavy metal and power metal, 3D resin printing miniatures, or hitting the weights for physical conditioning. I approach both code and life with a builder's mindset: put in the heavy lifting, refine the mechanics, and create something that lasts.
